
DATA SOURCES

This project uses data from the following sources:

1. Natural Earth
   Admin 0 – Countries (110m Cultural Vectors)
   https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/

   Used for:
   - Country boundaries
   - Land-area geometry
   - Geographic land/sea classification

2. United Nations – World Population Prospects (WPP)
   https://population.un.org/wpp/

   Used for:
   - Global population data
   - Population-based probability weighting
   - Crude Birth Rate (CBR) data

These datasets are used as inputs for the mathematical probability
models developed in this project.
